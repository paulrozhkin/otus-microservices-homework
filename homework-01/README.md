# otus-microservices-homework-01

## Задание

Выполнить декомпозицию архитектурной задачи интернет-магазина на несколько микросервисов с учетом будущих изменений.

В качестве архитектурной задачи используется ката **I’ll Have the BLT**:  
https://nealford.com/katas/list.html

Необходимо использовать один из паттернов декомпозиции и предложить вариант разбиения системы на микросервисы.

## В качестве решения предоставить

1. Описать пользовательские сценарии.

2. Подготовить схему взаимодействия сервисов в виде **C4 Model Container Diagram**.

3. Для каждого микросервиса описать:
   * его назначение;
   * зону ответственности.

4. Описать контракты взаимодействия микросервисов друг с другом.
