# otus-microservices-homework-01

## Задание

Выполнить декомпозицию архитектурной задачи интернет-магазина на несколько микросервисов с учетом будущих изменений.

В качестве архитектурной задачи используется ката **I'll Have the BLT**:
https://nealford.com/katas/list.html

Необходимо использовать один из паттернов декомпозиции и предложить вариант разбиения системы на микросервисы.

## В качестве решения предоставить

1. Описать пользовательские сценарии.

2. Подготовить схему взаимодействия сервисов в виде **C4 Model Container Diagram**.

3. Для каждого микросервиса описать:
   * его назначение;
   * зону ответственности.

4. Описать контракты взаимодействия микросервисов друг с другом.

## Решение

Для BLT выбрано разбиение по бизнес-возможностям. Получилось пять сервисов: точки продаж, меню и акции, заказы, исполнение и платежи.

## Шаги выполнения

1. Разобраны условия каты: как покупатель делает заказ, какие есть варианты доставки и оплаты, чем отличаются точки разных владельцев. Условия, которых в задании нет, вынесены в [допущения](docs/architecture.md).
2. Описаны [пользовательские сценарии](docs/architecture.md): от выбора сэндвича до выдачи заказа. Добавлены действия сотрудников, доставщика и владельца точки, а также ситуации с отказом и ошибкой оплаты.
3. Разделена система на сервисы. Для каждого указаны, за что он отвечает и какие данные хранит. Меню и акции оставлены вместе, поскольку они участвуют в расчете цены. Кухня и доставка объединены в сервис исполнения заказа. Подробнее - в [разделе о декомпозиции](docs/architecture.md).
4. Нарисована [Context Diagram](docs/context.md), чтобы обозначить пользователей и внешние системы. Затем составлена [C4 Container Diagram](docs/containers.md) с сервисами, базами данных и связями между ними.
5. Описаны [контракты](docs/contracts.md): какие запросы сервисы отправляют друг другу, какие события публикуют и что происходит при ошибках.
6. Добавлена основная [диаграмма последовательности](docs/processes.md). На них разобраны создание заказа, самовывоз с онлайн-оплатой, доставка с оплатой курьеру и возврат после отмены.
7. Обосновано, как выбранное разбиение учитывает рост сети и выход в другие страны. Оставшиеся вопросы по акциям, срокам оплаты и возвратам записаны в конце [описания архитектуры](docs/architecture.md).
